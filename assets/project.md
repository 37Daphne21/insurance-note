## Hero 개발 원칙 (확정)

- clamp()를 기본으로 사용한다.
- 구조 변경 시에만 Media Query를 사용한다.
- 구조가 변경되면 내부 Typography / Padding / Spacing도 함께 조정한다.
- min-height에 의존하지 않고 콘텐츠 중심으로 레이아웃을 설계한다.
- 긴 문구와 운영 데이터를 고려한 구조를 유지한다.
- 컴포넌트를 하나의 단위로 설계한다.
- Hero는 추후 실제 자료 반영 시 카피와 이미지만 수정한다.

---

## 개발 원칙

### Layout

- 데이터 추가/삭제를 고려한다.
- 긴 문구에도 레이아웃이 유지된다.
- 특정 개수에 의존하지 않는다.
- max-width로 줄바꿈을 제어하지 않는다.
- 운영 프로젝트처럼 설계한다.

### Responsive

- PC와 Mobile을 동시에 고려한다.
- PC와 Mobile은 같은 화면을 축소하지 않는다.
- 디바이스 특성에 맞는 UX를 각각 설계한다.
- 컴포넌트 크기가 변경되면 내부 요소도 함께 비율을 조정한다.
