# Insurance Note (보험한장)

## Project Overview

보험한장은 보험 상품을 어렵게 설명하는 기존 보험 사이트와 달리,

**"필요한 보장을 한 장으로 쉽게"**

라는 컨셉으로 제작하는 보험 랜딩 프로젝트입니다.

광고를 통해 유입된 사용자가 자신의 상황에 맞는 보험을 쉽고 빠르게
이해하고 상담까지 자연스럽게 이어질 수 있도록 설계합니다.

---

## Project Goals

* 보험 같지 않은 보험 사이트
* 모바일 광고 유입 최적화
* 상담 전환 중심 UX
* 보험별 개별 랜딩 + 메인 랜딩 구조
* 쉽고 직관적인 정보 전달

## Design Direction

### Do

* 넓은 여백
* 카드 기반 UI
* 높은 가독성
* 최소한의 텍스트
* 감성적인 접근
* 실사 + 카드 UI 혼합

### Don't

* 전형적인 보험사 홈페이지
* 과한 그라데이션
* 강한 그림자
* 정보 과밀
* 긴 문구에 의존하는 레이아웃
* 올드한 보험 디자인

## UX Strategy

### Desktop

* 정보 탐색 중심
* 높은 정보 밀도
* 여러 정보를 한 화면에서 비교

### Mobile

* Storytelling Landing
* 카드 기반 Flow
* 한 화면씩 자연스럽게 이어지는 경험
* 광고 유입에 최적화된 UX

## Development Principles

* Mobile First
* Responsive Design
* clamp() 우선 설계
* 구조 변경 시에만 Media Query 사용
* 구조 변경 시 내부 Typography / Padding / Spacing도 함께 조정
* 데이터 변경을 고려한 컴포넌트 설계
* 긴 문구와 운영 데이터를 고려한 레이아웃
* PC와 Mobile은 동일한 레이아웃 축소가 아닌 각각의 UX를 설계
