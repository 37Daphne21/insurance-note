# 보험한장 (Insurance Note)

## 프로젝트 소개

보험한장은 보험 상품을 어렵게 설명하는 기존 보험 사이트와 달리,

**"필요한 보장을 한 장으로 쉽게"**

라는 컨셉으로 제작하는 보험 랜딩 프로젝트입니다.

광고를 통해 유입된 사용자가 자신의 상황에 맞는 보험을 쉽고 빠르게
이해하고, 상담까지 자연스럽게 이어질 수 있도록 설계합니다.

------------------------------------------------------------------------

## 프로젝트 목표

-   보험 같지 않은 보험 사이트
-   모바일 광고 유입 최적화
-   상담 전환 중심 UX
-   메인 랜딩 + 보험별 개별 랜딩 구조
-   쉽고 직관적인 정보 전달

------------------------------------------------------------------------

## 디자인 컨셉

### 핵심 키워드

-   쉽다
-   간결하다
-   읽기 쉽다
-   신뢰감
-   핀테크 감성

### 디자인 참고

-   Toss : 60%
-   Bank Salad : 20%
-   Landing Page : 20%

------------------------------------------------------------------------

## 디자인 방향

### 지향하는 방향

-   넓은 여백
-   카드 기반 UI
-   높은 가독성
-   최소한의 텍스트
-   감성적인 접근
-   실사 + 카드 UI 혼합

### 지양하는 방향

-   전형적인 보험사 홈페이지
-   과한 그라데이션
-   강한 그림자
-   정보 과밀
-   긴 문구에 의존하는 레이아웃
-   올드한 보험 디자인

## UX 전략

### Desktop

-   정보 탐색 중심
-   높은 정보 밀도
-   여러 정보를 한 화면에서 비교

### Mobile

-   스토리텔링 랜딩
-   단계별 진행감이 있는 UX
-   카드 중심 Flow
-   한 화면씩 자연스럽게 이어지는 경험
-   광고 유입에 최적화된 UX
